Create a new Vue project called "employee-dashboard".

Use Vite with TypeScript and Vue Router. Add Vuetify 3 with Material Design Icons. Also install chart.js and vue-chartjs for data visualizations.

Project concept:
Build a P301 Operational Dashboard inspired by an employee experience / employee desktop project.

Industry:
Financial Services

Primary user:
Donor Services Associate or Dedicated Service Team Associate supporting donor-advised fund clients.

Dashboard purpose:
Help the employee quickly understand what needs attention at the start of the day, including active cases, SLA risks, follow-up tasks, queue status, recent touchpoints, client alerts, and daily performance metrics.

Core pages:
1. Dashboard page
2. Case Detail page

Dashboard modules:
- My Cases
- SLA Risk Alerts
- Follow-up Tasks
- Recent Touchpoints
- Queue Status
- Escalated Accounts
- Daily Metrics
- Calendar / Upcoming Meetings

Key interactions:
- Click a case to open the Case Detail page
- Filter or sort cases by priority, SLA, or status
- Show alert and status pills
- Include realistic empty states and loading states
- Make the layout responsive for desktop and tablet

Design direction:
Create a polished enterprise dashboard that feels modern, calm, and professional. The design should feel specific to financial services and employee operations, not like a generic dashboard template. Use clear hierarchy, cards, tables, status pills, and data visualizations.

Repo setup:
Create a README.md and BRIEF.md in the root of the repo. Add a /docs folder for project notes and AI context.

After setting up the project, open it and make sure it runs locally.
